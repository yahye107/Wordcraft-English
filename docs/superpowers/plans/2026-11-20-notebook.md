> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the personal notebook: save expressions from the library or add your own, keep your meaning, notes, own example sentences and collections, review them with spaced repetition (SM-2), and import the existing Obsidian reading notes.

**Architecture:** New learner tables (never touched by content seeding) plus pure, tested logic for scheduling, queue building and import parsing. Route handlers are thin wrappers around functions that take an injected `Db`, as in Phase 3. Pages are server components with small client components for forms and the review session.

**Tech Stack:** Same as before. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-19-wordcraft-design.md` (sections 6 and 10, Phase 5). Builds on the Phase 1 to 4 plans.

## Review Focus

1. Saving the same library expression twice returns the existing entry and creates no duplicate or second card; a custom word is unique ignoring case and spaces.
2. Deleting an entry deletes its card, review logs, examples and collection links; deleting a collection leaves its entries; removing an expression from the content leaves the entry and the page still renders.
3. SM-2 edges: Again resets repetitions and returns the card tomorrow-or-sooner, ease never drops below 1.3, Easy lengthens the interval, intervals are whole days of at least 1, and grading a card that is not yet due returns 409 and records nothing.
4. The review queue never returns the same card twice, never exceeds 50, respects the daily new-card limit, and an empty queue shows a friendly "nothing due" state.
5. The importer never throws: CRLF line endings, a callout with no meaning, a callout with no word, duplicated words in one file, wiki links and non-ASCII characters, an empty file, and a file with no callouts at all. A file over 1 MB is refused. Re-importing the same file adds nothing new.
6. Over-long text in any field returns 400 and stores nothing; collection names are trimmed and unique ignoring case.
7. An imported word that matches a library expression is linked to it and shows the library meaning next to the user's, without replacing the user's meaning.

### Task 2: SM-2 scheduler

**Files:**
- Create: `src/lib/srs/schedule.ts`
- Test: `tests/srs/schedule.test.ts`

**Interfaces:**
- Produces: `type Grade = 'again' | 'hard' | 'good' | 'easy'`; `type CardState = { ease: number; intervalDays: number; reps: number; lapses: number; dueAt: string; lastReviewedAt: string | null }`; `newCardState(now: Date): CardState` (ease 2.5, interval 0, reps 0, lapses 0, due at `now`); `schedule(card: CardState, grade: Grade, now: Date): CardState`.
- Rules (SM-2 adapted to four buttons): quality again=1, hard=3, good=4, easy=5. If quality is below 3 (again): `reps = 0`, `lapses += 1`, `intervalDays = 1`. Otherwise `reps += 1`; interval is 1 for the first success, 6 for the second, then `round(previous interval * ease)`; hard multiplies the interval by 1.2 instead (never less than previous + 1), easy multiplies by an extra 1.3. Ease update `ease += 0.1 - (5 - q) * (0.08 + (5 - q) * 0.02)`, never below 1.3. `dueAt = now + intervalDays` as an ISO string; `lastReviewedAt = now`. Intervals are whole days and at least 1.

### Task 4: Obsidian note importer

**Files:**
- Create: `src/lib/notebook/importer.ts`
- Test: `tests/notebook/importer.test.ts`, with sample text taken from the shape of the user's real notes (invented words and meanings, not the user's text)

**Interfaces:**
- Produces: `type ParsedNote = { text: string; meaning: string; source: string | null }`; `parseObsidianNotes(input: string): ParsedNote[]`: finds callouts that start with `> [!PDF|` followed by a wiki link (take the display text after `|` inside `[[...]]` as `source`, for example "The Giver - Lois Lowry, p.3"), then reads the first following line with `> > ` or `> ` prefix as the word and the remaining quoted lines as the meaning, joined by a space; strips the quote prefixes and surrounding spaces; keeps the user's spelling exactly; skips a callout with no word; accepts CRLF; never throws on any string; returns at most 5,000 notes.
- `importNotes(db, notes: ParsedNote[]): { added: number; skipped: number; linked: number }`: adds each as a `kind = 'import'` entry with an SRS card, skipping any whose `lower(trim(text))` already exists as a notebook entry (custom, import, or a library entry with the same expression text); when the word matches a published expression by text or by slug, stores that `expression_slug` so the library meaning shows beside the user's (count in `linked`; do not overwrite the user's meaning).
- `importFile(db, text: string): { ok: true; added; skipped; linked; found: number } | { ok: false; error: string }` refuses text over 1,000,000 characters.
